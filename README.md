# 自然人格原型测试 — 付费转化 Demo

好奇心驱动的内容付费墙演示:通过交互投入 + 控制内容完整度制造好奇心缺口,双路径转化(¥9.9 模拟支付 / 邀请 3 位好友病毒解锁)。**不接真实支付,仅为商业模型 demo。**

## 体系

- **测量层**:IPIP 大五人格结构改编,20 题「是/不确定/否」判断式短量表(每维 4 题,含反向计分)
- **术语层**:独创「自然原型」体系 — 五维大白话命名(探索欲/行动力/共情力/秩序感/定力),前四维高低组合出 16 原型,定力决定 静水型/浪潮型,共 32 种结果
- **视觉**:「科考手记」方向 — 纸灰底、墨绿油墨、苍松主色、赭金标记稀有/锁定,等高线为签名元素(呼应"人格地貌")
- 右上角「重置演示」可反复演示

## 结构

- `lib/data.ts` — 题库、原型表、文案(改测试主题只需改这里)
- `lib/scoring.ts` — 量表计分与原型匹配(常模百分位为占位换算)
- `lib/draw.ts` — 分享海报 / 假二维码 Canvas 绘制
- `components/` — 落地页、答题、分析动画、结果页、付费墙、分享、收银台
- `app/page.tsx` — 状态机编排(localStorage 持久化)

## 运行与部署

```bash
npm install
npm run dev        # http://localhost:3000
```

部署到 Vercel:推到 GitHub 后在 vercel.com 导入仓库,或直接 `npx vercel`。无环境变量、无数据库依赖。
